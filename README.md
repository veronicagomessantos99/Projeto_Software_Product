# Projeto_Software_Product

Projeto de BI para Loja de Roupas Meteora, novas e usadas- Faculdade Impacta

Projeto acadêmico de Business Intelligence desenvolvido em DataStudio, com foco na análise de dados fictícios do e-commerce Meteora, onde o nicho é de venda de roupas.
Trata-se de um projeto estruturado de forma evolutiva, no qual novas análises são integradas a cada ciclo de entrega acadêmica.


# Tecnologias Utilizadas

- DataStudio
- DBEAVER
- CSV
- xlsx.
- GitHub

# AC1 — Análise de Vendas

A primeira entrega do projeto tem como foco a análise de desempenho da loja Meteora de roupas novas e usadas

# Principais indicadores

- Lucro por estado;
- Visão geral do Lucro, Receita e Margem de Lucro;
- Número de vendas por Vendedor.

# Filtros disponíveis

- Estado;
- Ano de Venda;
- Marca.
  
Os indicadores e gráficos são atualizados dinamicamente conforme os filtros selecionados
